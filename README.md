# Peter Bonos — Personal Website

GitHub-ready static website package.

## Files
- `index.html` — homepage and booking-focused portfolio
- `resume.html` — web-native résumé
- `instruments.html` — instrument collection
- `gallery.html` — photo gallery/lightbox
- `styles.css` — shared styling
- `site.js` — shared interactions/contact-form behavior
- `assets/` — photos, performance video and downloadable PDF résumé

## Uploading to GitHub
Upload **the contents of this folder** to the root of `peterbonos-bot/personal-website`.
Do not upload the ZIP itself as the website content.

## GitHub Pages
After committing the files:
1. Open the repository **Settings**
2. Choose **Pages**
3. Under **Build and deployment**, select **Deploy from a branch**
4. Choose the `main` branch and `/ (root)`
5. Save

GitHub will show the public site URL after deployment.

## Contact form
Because this is a static site, the form prepares an email in the visitor's local mail app addressed to `peterbonos@gmail.com`. A hosted form service can be added later if desired.
